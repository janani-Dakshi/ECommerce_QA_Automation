#E-Commerce QA Automation Framework

## Overview

A Python-based QA Automation framework for testing an e-commerce application using selenium, Pytest, POM and API testing.

## Tech Stack
-Python
-Selenium WebDriver
-Pytest
-POM
-REST API testing
-Requests
-Git & Github
-Github Actions
-HTML Reports

## Test Coverage

-Valid login
-Invalid login
-Add products to cart
-Checkout flow
-Product API Validation
-Invalid Product API

## Framework Features

-POM
-Reusable login fixture
-Reusable explicit wait utility
-Centralized test data
-Screenshot capture on failure
-HTML test reports
-CI execution using Github Actions
